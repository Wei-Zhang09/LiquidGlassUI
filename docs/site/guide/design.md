# 设计原则

## 液态玻璃不是「透明 + 模糊」

普通的 glassmorphism 配方是：半透明底 + `backdrop-filter: blur()` + 白边框。
这套配方在任何背景上看起来都差不多，因为它**没有让光发生偏折** ——
只是把背景磨砂了。

液态玻璃的判据是**边缘折射**：玻璃的边像一块透镜，把背后的东西压缩、位移。

| | 普通 glassmorphism | 液态玻璃 |
|---|---|---|
| 中心 | 模糊 | 模糊（一样） |
| 边缘 | 模糊 | **位移 + 压缩**（关键差异） |
| 观感 | 一块磨砂板 | 一块有厚度的玻璃 |

## 材质的九个要素

按重要性排序。前三条是**必须**，后面是提升。

### 1. 背景光场（地基）

没有东西可折射，玻璃就不存在。见[快速开始](/guide/quickstart) § 2。

### 2. 边缘折射

通过 SVG 位移贴图（Web）或运行时着色器（Compose）实现。
位移量由**边缘高度函数**决定：

| 曲面 | 公式 | 形态 |
|---|---|---|
| `convexSquircle` | `(1 − (1 − x)⁴)^0.25` | 苹果超椭圆（默认） |
| `convexCircle` | `√(1 − (1 − x)²)` | 半圆凸起 |
| `concave` | `1 − √(1 − (1 − x)²)` | 内凹（水滴边缘） |
| `lip` | 凸→凹混合 | 边缘有卷边 |

真实玻璃的边缘是**凸起**的（像透镜），所以折射在边缘处偏折最大、
向内迅速归零 —— 这就是"边缘弯折、中心干净"的来源。

### 3. 边缘高光（不是边框）

用**渐变**而不是实心白边框。实心白边框是廉价玻璃感的主要来源。

```css
/* 对的：渐变高光 */
:host::before {
  background: linear-gradient(45deg, transparent, rgba(255,255,255,0.5) 42%, transparent 72%);
  mix-blend-mode: screen;
}

/* 错的：实心白边框 */
border: 1px solid white;
```

### 4. 内外阴影

外阴影给深度，内阴影给厚度感。

```css
box-shadow:
  0 18px 55px rgba(57, 80, 103, 0.11),      /* 外：深度 */
  0 2px 8px rgba(35, 54, 73, 0.06),
  inset 1px 1px 0 rgba(255,255,255,0.78),   /* 内：厚度 */
  inset -1px -1px 0 rgba(103,127,151,0.10);
```

### 5. 统一光源

**永远左上**。所有组件、所有平台都用同一个方向。光源不一致是最容易
被察觉但最难说清的问题。

### 6. 材质层级

| 层级 | 模糊 | 用途 |
|---|---|---|
| `plain` | 0 | 只有边框高光，不要模糊 |
| `regular` | 8px | 常规面板 |
| `elevated` | 16px | 浮起的卡片 |
| `focused` | 30px | 当前焦点、浮层 |

不要所有元素都用同一个层级 —— 那样深度关系就没了。

### 7. 圆角系统

| 名称 | 值 | 用途 |
|---|---|---|
| `sm` | 10px | 小控件 |
| `md` | 18px | 卡片 |
| `lg` | 26px | 内容面板（默认） |
| `xl` | 32px | 浮动窗口 |

圆角应随元素尺寸成比例。

### 8. 色散

高对比边缘上，红蓝通道的位移量略有差异，产生彩虹边。
本库的 `aberrationIntensity` / `chromaticAberration` 控制这个。
**轻微**即可 —— 过度会显得廉价。

### 9. 动效

悬停时轻微上浮 + 阴影加深。不要做夸张的形变。

## 可读性优先

::: warning 最重要的一条
**文字对比度优先于材质还原。**

玻璃是背景层。当二者冲突时，降玻璃的透明度、加内容的底色，
而不是让用户眯着眼读。
:::

这也是模态对话框用更高不透明度（约 0.82）而不是普通玻璃（约 0.44）的原因。

## 反模式清单

- ❌ 所有元素用同样的玻璃强度
- ❌ 用实心白边框代替渐变高光
- ❌ 在纯色背景上放玻璃
- ❌ 光源方向不一致
- ❌ 为了玻璃效果牺牲文字对比度
- ❌ 每个面都做玻璃（保留一些实心区域）
- ❌ 霓虹渐变、彩虹配色、过度发光
- ❌ 声称 Safari / Firefox 有完整折射支持（它们没有）
