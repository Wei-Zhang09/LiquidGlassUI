GlassGroup — 玻璃融合

相邻玻璃不是叠放，而是把距离场做平滑并集（SDF smooth min）后 按融合轮廓折射 —— 交界处是一整块液体，不会出现两道互相打架的折射边。 调整下方 smoothing 可看到融合强度变化。

GlassSegmented — 分段控件

跨端语义一致的少数控件之一。键盘遵循 radiogroup 惯例： 方向键移动、Home/End 跳首尾；roving tabindex 让整组只占一个 Tab 位。

当前：周

GlassDialog — 模态对话框

自绘遮罩（原生 <dialog> 的 ::backdrop 不支持 backdrop-filter，玻璃会退化）。含焦点陷阱、焦点归还、ESC 关闭、滚动锁定。

打开对话框

GlassBottomBar — 移动端形态

与顶部导航对应，但交互模型不同：条目等宽、图标在上文字在下、无悬停态（触屏没有 hover）。

GlassSwitch — 开关

role="switch" + aria-checked，空格/回车切换。 开关是移动端设置页高频控件，交互模型两端一致。

启用通知 禁用态 当前：开

GlassSlider — 滑块

用 Pointer Events 统一鼠标与触摸。触屏两个坑：touch-action: none 阻止拖动被当成页面滚动；setPointerCapture 让手指移出元素后仍能拖动。
